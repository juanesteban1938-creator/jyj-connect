# **App Name**: J&J Connect V2.0

## Core Features:

- User Authentication: Secure login using the provided email (transportes.especialesjyj@gmail.com) and password (Kamus1938*) to access the admin panel.
- Dashboard: A central hub providing access to all modules: Home, Conductores (Drivers), Vehículos (Vehicles), Servicios (Services), Monitoreo (Monitoring), Rentabilidad (Profitability), Facturación y Cartera (Billing and Portfolio), and Cerrar Sesión (Logout).
- Home Module: A welcome page within the dashboard providing a greeting message.
- Conductores Module: Manage driver information, schedules, and performance metrics.
- Vehículos Module: Track vehicle information, maintenance schedules, and status.
- Servicios Module: Manage and schedule transportation services.
- Monitoreo Module: Real-time monitoring of vehicle locations and service status.

## Style Guidelines:

- Primary color: Light white background (#FAFAF9) for a clean and professional look.
- Accent color: Vibrant orange (#FF8C00) for buttons and interactive elements to draw attention.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text, offering a balance of modern clarity and readability.
- Use distinct icons to represent each module within the dashboard, enhancing user navigation and visual appeal.
- Responsive layout design ensuring seamless usability across devices, maintaining consistent branding.
- Subtle transitions and animations on button hover states to enhance user engagement.
